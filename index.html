SCENE 02 // SILICON ARCHITECTURE

Transistor Mechanics: BJT vs MOSFET

The fundamental difference lies at the atomic silicon level: Current-driven bipolar junctions vs electric-field voltage-driven insulated gates.

74LS TTL: BIPOLAR BJT Current-Driven
Constant Base Current: Requires continuous current flow (~0.4 mA) even when idle, producing steady heat and static power loss.
74HC: CMOS COMPLEMENTARY MOS Field-Effect
Insulated SiO2 Oxide Gate: Gate impedance exceeds $10^{12}\,\Omega$. Zero static current flows through inputs; power is consumed only during switching transitions!

SCENE 05 // CURRENT & DRIVE CAPABILITY

Fan-Out: 20 Gates vs 4,000+ Gates

How many standard inputs can a single output driver control before signal degradation occurs?

74LS TTL FAN-OUT
20
$I_{OL} = 8.0\text{ mA} \div I_{IL} = 0.4\text{ mA} = 20\text{ loads}$
Heavily limited by DC sink current.
74HC CMOS FAN-OUT
4,000+
$I_{in} \le 1\text{ }\mu\text{A}$ gate leakage.
Nearly limitless at low frequencies; limited by capacitance $C_L$.

SCENE 07 // POWER CONSUMPTION

Static vs Dynamic Power

TTL drains continuous static current ($1-4\text{ mA}$) around the clock. CMOS consumes virtually ZERO static power ($< 1\text{ }\mu\text{A}$), scaling dynamically only during switching!

74LS TTL IC CHIP
74LS
Continuous Heat Sink: Drains $1-4\text{ mA}$ quiescent current ($I_{CC}$) even when completely static and idle.
74HC CMOS IC CHIP   (CLICK TO SWITCH)
74HC
Near-Zero Idle Current: Consumes $< 1\text{ }\mu\text{A}$ at rest! Dynamic power formula: $P = C \cdot V^2 \cdot f$.

SCENE 09 // SYSTEM INTEGRATION

The 74HCT Bridge Solution

Why can't TTL directly drive pure 74HC CMOS without pull-up? Because TTL's guaranteed $V_{OH,min} = 2.7\text{ V}$ is below 74HC's required $V_{IH,min} = 3.5\text{ V}$!

74HC
High-Speed Pure CMOS
Pure CMOS Architectures:
Wide supply voltage ($2\text{V} - 6\text{V}$), symmetrical 50% thresholds ($V_{IH}=3.5\text{V}, V_{IL}=1.5\text{V}$). Best for new all-CMOS embedded systems.
↓
Needs Pull-up to talk to legacy TTL outputs.
74HCT
TTL-Compatible CMOS
Legacy Factory Retrofitting:
Engineered with TTL input levels ($V_{IH}=2.0\text{V}, V_{IL}=0.8\text{V}$) and CMOS output stages ($V_{OH}=4.4\text{V}$). Direct drop-in replacement!
✓
Zero extra components required! Direct connection.
